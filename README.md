# LUMÉA – Skincare Website

LUMÉA is a modern and responsive skincare e-commerce website designed to provide a clean, elegant, and user-friendly shopping experience.

## 🌐 Live Website

https://prasad-golla.github.io/LUMEA-skincare/

## 💻 GitHub Repository

https://github.com/prasad-golla/LUMEA-skincare

## ✨ Features

- Modern and responsive skincare website design
- Attractive homepage with hero section
- Featured skincare products
- Product listing page
- Individual product details
- Add products to cart
- Remove products from cart
- Shopping cart functionality
- Cart data stored using Local Storage
- Responsive design for different screen sizes
- Simple and user-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- GitHub Pages

## 📄 Website Pages

- `index.html` – Home page
- `products.html` – Products page
- `product-details.html` – Product details page
- `cart.html` – Shopping cart page
